## this is my nixos config

I am just learning to use/configure nix/nixos so I am probably doing some things wrong. You can probably let me know somewhere :)

The hardware-configuration.nix and hardware-acceleration-hybrid.nix are specific for my Acer Predator Helios 300 with an intel i7-7700HQ (integrated intel HD graphics 630) and a nvidia GeForce GTX 1060

### layout

This repo *is* `/etc/nixos`. Clone it there (or symlink it) and `sudo nixos-rebuild switch`.

| file | what |
| --- | --- |
| `configuration.nix` | just the import list + `system.stateVersion` |
| `hardware-configuration.nix` | generated by `nixos-generate-config`, plus the `rust1tb` data disk. **UUIDs change on reinstall** |
| `bootloader.nix` | systemd-boot |
| `network.nix` | hostname, NetworkManager, tailscale |
| `i18s.nix` | timezone, es_ES locale, es console keymap |
| `audio.nix` | pipewire |
| `user-pep.nix` | the user, fish as login shell |
| `packages-and-services.nix` | system packages, GNOME, docker, flatpak, openssh, printing |
| `hardware-acceleration-hybrid.nix` | VA-API + nvidia PRIME **offload** (imported) |
| `hardware-acceleration.nix` | intel-only VA-API variant (not imported) |
| `gpu-WIP.nix` | scratch nvidia config (not imported) |

### notes (2026-09-23 reinstall, NixOS 26.05 "Yarara")

- `stateVersion` is now `26.05`.
- The `<unstable>` channel is no longer used; `android-tools` / `android-studio`
  come from the normal channel. `addUnstableChannel.sh` + the commented `let`
  block in `packages-and-services.nix` bring it back if needed.
- Renamed nixpkgs attrs: `vaapiIntel` -> `intel-vaapi-driver`,
  `vaapiVdpau` -> `libva-vdpau-driver`.
- Moved options: `services.xserver.displayManager.gdm` -> `services.displayManager.gdm`,
  `services.xserver.desktopManager.gnome` -> `services.desktopManager.gnome`.
- The GTX 1060 is Pascal. NVIDIA dropped Maxwell/Pascal/Volta after the 580
  branch, so `hardware.nvidia.package` is pinned to `nvidiaPackages.legacy_580`.
  `stable`/`production` (595.x) will not drive this card.
- PRIME is in **offload** mode: run GPU-hungry things with `nvidia-offload <cmd>`.
