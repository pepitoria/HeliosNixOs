## this is my nixos config

I am just learning to use/configure nix/nixos so I am probably doing some things wrong. You can probably let me know somewhere :)

This is the config for **helios**, my Acer Predator Helios 300: intel i7-7700HQ
with integrated intel HD graphics 630, plus a nvidia GeForce GTX 1060. It follows
the same layout as my main machine's config (`maggie`) so the two stay in sync —
`hardware-configuration.nix` and `import-08-gpu.nix` are the host-specific bits.

The repo *is* `/etc/nixos`.

### layout

| file | what |
| --- | --- |
| `configuration.nix` | import list, nix gc/optimise, `system.stateVersion` |
| `hardware-configuration.nix` | generated by `nixos-generate-config`, plus the `rust1tb` data disk. **UUIDs change on reinstall** |
| `import-00-bootloader.nix` | systemd-boot, zen kernel |
| `import-01-user.nix` | the user `pep`, fish as login shell |
| `import-02-network.nix` | hostname, NetworkManager, tailscale, wireguard-tools |
| `import-03-i18s.nix` | timezone, es_ES locale, es console keymap |
| `import-04-audio.nix` | pipewire |
| `import-05-desktop-gnome.nix` | GNOME + GDM |
| `import-05-desktop-hyprland.nix` | Hyprland session offered from the same GDM |
| `import-06-packages.nix` | packages, programs, AppImage, nix-ld, flatpak |
| `import-07-services.nix` | docker, steam, openssh, sunshine, printing |
| `import-08-gpu.nix` | **host-specific**: Intel VA-API + NVIDIA PRIME offload |
| `scripts/` | `nurse.sh` (rebuild switch), `nurse-update.sh` (switch --upgrade), channel helpers |
| `hypr-quickshell-config/` | Hyprland/Quickshell/wofi dotfiles, copied into `~/.config` by hand |

### notes

- **NVIDIA:** the GTX 1060 is Pascal, and NVIDIA dropped Pascal after the 580
  branch, so `hardware.nvidia.package` is pinned to `nvidiaPackages.legacy_580`.
  The channel default (595.x) will not drive this card.
- **PRIME offload:** Intel drives the display, the 1060 spins up on demand.
  Use `nvidia-offload <cmd>`.
- **No `<unstable>` channel here** — everything maggie takes from unstable is in
  the 26.05 stable channel. The `let` bindings are left commented out in case
  that changes; `scripts/add-channel-unstable.sh` re-adds the channel.
- **Dev toolchains (android, flutter, AI CLIs) are commented out** in
  `import-06-packages.nix`. This is a secondary machine.
- `system.stateVersion` is `26.05` here (maggie is `25.05`). Don't change it.
